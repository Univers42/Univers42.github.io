POSIX SHELL & TDD • ★ 54 STARS

hellish

Nacido tras las batallas de Minishell y 42sh. En vez de un parser improvisado con fallos en pipes, hellish fue concebido bajo metodología estricta de Test-Driven Development (TDD) y técnicas DevOps. Manejo POSIX impecable, pipelines bidireccionales, redirecciones compuestas, variables de entorno y cero fugas de descriptores de archivo.

  • Parser determinista con AST completo y compatibilidad POSIX.
  • Pipelines bidireccionales y gestión de señales robusta (SIGINT, SIGQUIT).
  • Batería de pruebas automatizadas con integración continua.

src/parser/ast_exec.c Language: C 
t_ast_node *parse_pipeline(t_lexer *lex) {
    t_ast_node *node = parse_command(lex);
    while (match_token(lex, TOKEN_PIPE)) {
        t_ast_node *pipe_node = ast_node_new(NODE_PIPE);
        pipe_node->left = node;
        pipe_node->right = parse_command(lex);
        node = pipe_node;
    }
    return node;
}
MEMORY SAFETY & HEAP TRACING • ★ 22 STARS

Torturette

El destructor de memory leaks definitivo para el cursus de 42. Intercepta llamadas a malloc, calloc, realloc y free mediante hooks en tiempo de compilación. Detecta punteros colgantes (dangling pointers), doble liberación (double-free) y accesos fuera de rango antes de que la Moulinette te asigne un cero.

  • Rastreo determinista bloque a bloque con mapas de direcciones virtuales.
  • Compatible con Valgrind y AddressSanitizer (ASan) sin interferencias.
  • Informe visual con la línea exacta y archivo donde ocurrió la fuga.

tracer/alloc_hook.c Language: C 
void *tracked_malloc(
    size_t size,
    const char *file,
    int line
) {
    void *ptr = real_malloc(size);
    if (!ptr)
        return NULL;
    t_alloc_record rec = {
        .addr = (uintptr_t)ptr,
        .bytes = size,
        .origin = file,
        .line_no = line
    };
    record_insert(&g_heap_registry, rec);
    return ptr;
}
EXAMSHELL SIMULATION & GRADING • ★ 8 STARS

codewar

La ansiedad del examen de 42 desaparece cuando has entrenado 50 veces bajo las mismas condiciones. codewar simula con fidelidad matemática el entorno de examen de 42: cuenta atrás de 3 horas, enunciados aleatorios por Rank, pruebas automáticas con diff estricto y puntuación inmediata.

  • Batería completa de ejercicios desde Rank 02 hasta Rank 04.
  • Modo práctica con pistas y modo examen estricto sin internet.
  • Grading automático contra casos límite y comprobación de Norminette.

engine/diff_checker.py Language: Python 
def evaluate_solution(
    binary_path, reference_path, test_cases
):
    passed = 0
    for inp in test_cases:
        user_out = run_isolated(binary_path, inp, timeout=1.0)
        ref_out = run_isolated(reference_path, inp, timeout=1.0)
        if user_out.stdout != ref_out.stdout:
            return GradeResult(success=False, error_at=inp)
        passed += 1
    return GradeResult(success=True, score=100)
RUST & CYBERSECURITY PLATFORM • ★ 6 STARS

42ctl & vault42

Suite de herramientas de seguridad en Rust construida bajo arquitectura zero-knowledge. vault42 cifra y gestiona credenciales de API, tokens de intra y variables de entorno de tus proyectos sin guardar secretos en texto plano, mientras que 42ctl unifica la distribución multi-canal vía Homebrew Tap.

  • Cifrado autenticado ChaCha20-Poly1305 con derivación Argon2id.
  • CLI en Rust sin dependencias externas pesadas ni memory leaks.
  • Homebrew Tap oficial para instalación en macOS y Linux con 1 comando.

src/crypto/vault.rs Language: Rust 
pub fn encrypt_secret(
    payload: &[u8], 
    key: &Key
) -> Result<CipherEnvelope, Error> {
    let cipher = ChaCha20Poly1305::new(key);
    let nonce = generate_nonce(&mut OsRng);
    let ciphertext = cipher.encrypt(&nonce, payload)
        .map_err(|_| Error::EncryptionFailed)?;
    Ok(CipherEnvelope { nonce, ciphertext })
}
