POSIX SHELL & TDD • ★ 54 STARS

hellish

Nacido tras las batallas de Minishell y 42sh. En vez de un parser improvisado con fallos en pipes, hellish fue concebido bajo metodología estricta de Test-Driven Development (TDD) y técnicas DevOps. Manejo POSIX impecable, pipelines, redirecciones compuestas, variables de entorno y cero fugas de descriptores.

  • Parser determinista con AST completo y compatibilidad POSIX.
  • Pipelines bidireccionales y gestión de señales robusta (SIGINT, SIGQUIT).
  • Batería de pruebas automatizadas con integración continua.

src/parser/ast_exec.c Language: C 
t_ast_node *parse_pipeline(t_lexer *lex) {
    t_ast_node *node = parse_command(lex);
    while (match_token(lex, TOKEN_PIPE)) {
        t_ast_node *pipe_node = ast_node_new(NODE_PIPE);
        pipe_node->left = node;
        pipe_node->right = parse_command(lex);
        node = pipe_node;
    }
    /* 0 leaks, FD tracking active */
    return (node);
}
MEMCHECK & SANITIZER • ★ 22 STARS

Torturette

El salvavidas antes de la evaluación entre pares (Peer-Correction). Intercepta y monitoriza cada llamada a malloc, free y realloc en tiempo de ejecución. Te alerta de double-frees, punteros colgantes y bytes huérfanos antes de que Moulinette te mande un 0.

  • Rastreo dinámico de heap en C sin sobrecarga ni librerías externas.
  • Reporte detallado con número de allocations, frees y balances.
  • Fácilmente integrable con make test en cualquier proyecto.

RUST PLATFORM & SECURITY • CYBERSECURITY

42ctl & vault42

CLI paraguas de distribución multicanal y sistema de ciberdefensa en Rust. Permite gestión de secretos zero-knowledge, autenticación distribuida, enrutamiento a través de nodos Tor (con invisibility-cloak) y orquestación integral de la infraestructura del colectivo.

  • Cero conocimiento: los secretos nunca tocan memoria sin cifrado AES-256-GCM.
  • Distribución firmada con Homebrew Tap (`homebrew-tap/42ctl`).
  • Construido íntegramente con Rust y seguridad en concurrencia sin data races.

    nonce_gen: OsRng,

    }
